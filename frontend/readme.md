# Become the Leader – JavaScript

## Files
- `script.js` – Handles game interactions, choices, screen changes and updates.
- `api.js` – Connects the JavaScript frontend to the Python backend.

## Features
- Starting a new game
- Loading scenarios and choices
- Sending decisions to the backend
- Updating game indicators
- Showing game results and leaderboard

## Running the Project
1. Start the Python backend.
2. Open the frontend HTML file in your browser.
3. Make sure the API address in `api.js` is correct.
